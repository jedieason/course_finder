# 選課樂透｜臺大課程錄取率搜尋

一個可直接部署到 GitHub Pages 的純靜態單頁工具。使用者可以選擇可上課時段、加入想要與排除的關鍵字，接著查詢臺大課程網並依即時推估錄取率由低到高排序。

## 功能

- 星期一至星期六、`0–9 / X / A–D` 節次的互動式時間表
- 多個想要／排除關鍵字，想要關鍵字可選「符合任一」或「全部符合」
- 自動抓齊搜尋分頁，並以受控併發取得每門課的即時登記狀態
- 依 `剩餘名額 ÷ 已登記人數` 排序，並將無人登記的課程獨立列出
- 顯示歷史 A+ 率；優先匹配同課、同教師與同班次，無資料時改用教師其他課程平均
- 搜尋進度、取消搜尋、重試退避與錯誤提示
- 搜尋條件同步到網址，可直接分享條件連結
- 響應式設計，無套件、無建置步驟

## 本機預覽

直接開啟 `index.html` 即可。若瀏覽器限制 `file://` 頁面的網路請求，可在專案資料夾啟動任一靜態伺服器，例如：

```bash
python3 -m http.server 8080
```

接著開啟 `http://localhost:8080`。

## 部署至 GitHub Pages

1. 將此資料夾推送到 GitHub repository。
2. 到 repository 的 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇 `main` branch 與 `/ (root)` 後儲存。

網站入口即為根目錄的 `index.html`，不需要 GitHub Actions 或額外建置設定。

## 資料與限制

- 資料來自臺大課程網的公開內部 API；端點或欄位未來可能改變。
- 推估錄取率為 `registered > 0 ? min(100%, remaining / registered) : 無法估算`。
- 這不是校方保證的正式錄取率；真實結果仍可能受到加選方式、系所／年級限制、預配與保留名額影響。
- A+ 率來自歷史回報資料而非校方官方統計；教師 fallback 會先算各課程平均，再平均各門課，避免重複回報較多的課程權重過高。
- 工具不永久快取即時名額，重新搜尋會再次取得最新登記狀態。

詳細 API 邏輯見 [`ntu_course_api_codex_spec.md`](./ntu_course_api_codex_spec.md)。
